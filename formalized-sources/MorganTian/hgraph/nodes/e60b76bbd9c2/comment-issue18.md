`IsConjugatePointAt` is the explicit conjugate-point form: it quantifies a Jacobi pair with `J 0 = 0`, `J t₁ = 0`, and a witness `∃ t ∈ Icc 0 t₁, J t ≠ 0` (the endpoint cannot witness because `J t₁ = 0`). The minimizing theorem therefore concludes absence of a nonzero field with both endpoint vanishings for every `0 < t₀ < 1`. Its `[CompleteSpace M]` instance is retained as an implementation hypothesis; no claim is made that completeness is mathematically necessary.
