`exists_parallelFrameAlong` packages parallel fields and constant metric inner products along a geodesic crossing charts, assuming `a < b`, `IsGeodesicOn`, and pointwise continuity. It does not assert smoothness of an arbitrary curve or add a global frame beyond those hypotheses.
