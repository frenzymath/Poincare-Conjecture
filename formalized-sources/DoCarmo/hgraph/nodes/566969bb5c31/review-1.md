**def:dc-ch1-2-8** → `Riemannian.DCIsCurve`

TeX requires a smooth map on an **open interval**. `DCIsCurve c s` only says that `c` is smooth on an arbitrary set `s`; it does not require `IsOpen s` or that `s` is an interval.
