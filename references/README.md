# Reference blueprints

These books and articles provide mathematical background for the primary
[Poincare proof library](../PoincareConjecture/). They are blueprint-only:
their Lean modules, Lake packages and toolchain files have been removed.
The website retains their statements, mathematical proofs, dependencies,
citations and authored reviews, with Lean source discovery disabled.

Earlier source files and build records remain recoverable from Git history.
Historical development notes describe those earlier revisions, not active
formalization projects. Shared historical documentation under `shared/`
does not constitute a Lean package.
